How Network Path and Delay Analyzer Works

Core computer networking concepts, delay mechanics, and routing protocols implemented in this project.

🔢

TTL & ICMP Time Exceeded

Traceroute sends probe packets with an incrementing Time-To-Live (TTL) field in the IP header. Each intermediate router decrements the TTL by 1. When TTL hits 0, the router discards the packet and transmits an ICMP Type 11 (Time Exceeded) datagram back to the source, uncovering the router's IP address.

🔗

Routing Hops & Transit Paths

Packets traverse a series of intermediate routers ("hops") determined by BGP and interior routing tables (OSPF/IS-IS). Each hop forwards traffic toward the destination IP according to prefix matches, crossing Internet Exchange Points (IXPs) and inter-carrier transit links.

⏱️

Round-Trip Time (RTT)

The round-trip duration for a probe to reach an intermediate hop and return an ICMP response. We fire 3 consecutive probes per hop to calculate the minimum, maximum, and average RTT to capture short-term latency variance.

📶

The 4 Components of Network Delay

Total hop delay $D = d_{proc} + d_{queue} + d_{trans} + d_{prop}$. Propagation delay reflects distance (fiber speed of light ~200,000 km/s). Transmission delay ($L/R$) reflects link bandwidth. Queueing delay represents buffer backlog, and processing delay is router route-lookup time.

📉

Jitter (Delay Variation)

Jitter measures the statistical dispersion of consecutive packet latencies ($\Delta \text{RTT}$). Excessive jitter indicates fluctuating router queue depths, transient congestion, or route fluttering, which severely impairs real-time UDP streams like VoIP and video conferencing.

❌

Packet Loss & ICMP Deprioritization

Reported when probes time out (* * *). Intermediate hops often rate-limit ICMP responses or block them via firewall ACLs without impacting data forwarding. A persistent loss jump extending all the way to destination signals true congestion or link impairment.

🌍

DNS Forward & Reverse Resolution

Domain targets are resolved into IP addresses via recursive hierarchical DNS lookups. For discovered hops, asynchronous reverse-DNS queries (PTR records) resolve router interface hostnames to help uncover carrier node locations.

🏢

Autonomous Systems (ASN)

Each hop IP is correlated to its Autonomous System Number (ASN), identifying the commercial organization or ISP governing that network segment (e.g. Google AS15169, Cloudflare AS13335, Airtel AS9498).
